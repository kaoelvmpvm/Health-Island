# 健康島 Health Island

這是「健康島」的第一版 3D 空島實驗（v0.1）。**目前沒有放入任何健康教育教材、主題建築、任務或文字內容**，目的是先驗證：使用一般瀏覽器與 GitHub Pages，能把 3D 島嶼製作到什麼程度。

## 目前完成的視覺與互動

- 多層低多邊形浮島地形、草原與分層岩壁
- 程式生成的樹木、山丘、石頭、草叢、花朵
- 池塘、彎曲溪流、瀑布與浮島下方的動態水面
- 飄動雲層、飛鳥、夜間螢火蟲與星點
- 白天／夜晚切換，燈光與天空漸變
- 滑鼠拖曳旋轉、滾輪縮放，觸控裝置單指旋轉、雙指縮放
- 自動旋轉開關、重設視角
- 桌機與手機的響應式介面

所有地形和裝飾都是由 Three.js 在執行時產生，**不使用外購模型、圖片素材或後端資料庫**。

## 啟用公開展示（GitHub Pages）

1. 開啟此 Repository 的 **Settings → Pages**。
2. 在 **Build and deployment** 選擇 **Deploy from a branch**。
3. Branch 選擇 **main**，資料夾選 **/(root)**，按 **Save**。
4. GitHub 完成首次部署後即可開啟：

   https://kaoelvmpvm.github.io/Health-Island/

首次啟用 Pages 可能要一段時間才會出現網站；請以 Settings → Pages 的狀態為準。

## 使用與限制

本網站是靜態網站，無須安裝或建置工具。Three.js 透過 CDN 載入，因此第一次開啟時需要連線；瀏覽器須支援 WebGL 與 ES modules。這是一個設計實驗，尚未完成低階手機效能驗證、無障礙操作優化或正式教學內容系統。

下一步可在不更換 3D 技術底座的情況下，加入分區、建築、角色、可點擊熱點、教材資訊卡與任務系統。
