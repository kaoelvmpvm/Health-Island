# 健康島 Health Island

v0.4｜四島青春探索世界＋中央教材寶庫

這是一個使用 Three.js 製作的 3D 健康教育探索網站：保留中央原有的自然浮島，並且**在主島外圍額外建立三座真正分離的浮島**，而不是在同一塊地面上劃分主題區。

## 四座島

| 島嶼 | 主要視覺 | 學習入口 |
| --- | --- | --- |
| 健康島（中央主島） | 森林、池塘、溪流、瀑布 | 保留自然景觀，供後續擴充 |
| 不染色島 | 森林綠，樹木與草地 | 1-1 認知、2-1 情意、3-1 技能 |
| 不炫耀島 | 星光紫，水晶地景 | 1-2 認知、2-2 情意、3-2 技能 |
| 不迷路島 | 暖陽橘，陽光植栽 | 1-3 認知、2-3 情意、3-3 技能 |

三座主題島都是獨立生成的多層懸浮岩層地形，各有三座教材建築，中央主島與三座分島之間以漂浮踏石作為視覺連結。

## 中央教材寶庫（v0.4 新增）

中央健康主島新增一座可點擊的立體寶庫，設計為未來的「教材區」入口：

- 石造圓形基座、金色屋頂、巨大圓形寶庫門、寶箱、光點、中文「教材寶庫」招牌
- 在主島上預留植栽淨空區，不讓隨機生成的樹木與石塊擋住入口
- 點擊寶庫本體或浮動「教材寶庫」標記，顯示「教材區入口預留中」說明
- **目前不含任何連結、路由或自動跳轉，也未建立新的教材內容**
- 日後確定教材區的入口網址或互動方式後，再由 `vault.js` 接上功能

## 操作方式

1. 剛開啟網站是**四島總覽**，可同時看到中央健康島與三座外圍分島。
2. 點選浮島上的名稱標籤、浮島地表，或底部導覽列的「不染色島／不炫耀島／不迷路島」，鏡頭會拉近到指定分島。
3. 點選分島上的 3D 建築或教材浮動標籤，即可查看教材介紹與入口。
4. 點選「進入互動教材」在內嵌視窗使用原網站；若瀏覽器阻擋內嵌，可「另開分頁」。
5. 點選「四島總覽」或「重設視角」即可回到全景。支援旋轉、縮放、自動旋轉與日夜切換。
6. 右上角「四島探索地圖」可一次選擇九個教材入口，手機也能使用。

所有九份既有教材均以外部網址連結，沒有修改它們各自的 Repository。完整對應表在 `data/lessons.json`。

## 專案結構

| 檔案 | 功能 |
| --- | --- |
| `index.html`, `styles.css` | 基礎介面、品牌識別 |
| `app.js` | 中央主島、動態水面、天空、日夜系統、相機 |
| `vault.js`, `vault.css` | 中央寶庫的 3D 外觀、光效、點擊區與預留入口說明視窗 |
| `satellites.js` | 不染色島、不炫耀島、不迷路島的獨立地形、環境、天空踏石 |
| `lessons.js`, `learning.css` | 九座教材建築、分島導覽、資訊面板、嵌入視窗與響應式排版 |
| `data/lessons.json` | 青春系列九份教材資料 |

## 發布

Repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`。

網站預定位置：https://kaoelvmpvm.github.io/Health-Island/

以支援 WebGL、ES modules 的現代瀏覽器操作，首次載入需連線到 Three.js 的 CDN。本版本已進行檔案、程式語法和教材資料的靜態檢查；尚須以實際電腦、手機瀏覽器確認動畫效能、標籤位置及嵌入外站的效果。
