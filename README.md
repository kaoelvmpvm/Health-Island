# 健康島 Health Island

## v0.9｜教材下方直接輸入密碼 × 不染色島第二塔解鎖

使用 Three.js 建立的健康教育 3D 互動世界。中央健康主島有導覽小人與教材寶庫；周圍建有不炫耀島、不染色島與不迷路島，依據學習任務進度逐步出現。

### 已完成的可玩流程

| 階段 | 完成條件 | 世界變化 |
|---|---|---|
| 0 → 1 | 閱讀示範教材並答對兩題檢核 | **不炫耀島升起**，顯示 1-2 認知塔 |
| 1 → 2 | 完成 1-2 青春補給，輸入原遊戲青春密碼 **2499** | **2-2 情意塔**升起 |
| 2 → 3 | 完成 2-2 青春心語 Yes 徽章提示語製作，輸入通關密碼 **172** | **3-2 技能塔**升起 |
| 3 → 4 | 在 3-2 青春練功走出成功路徑，於遊戲下方輸入成功通關密碼 **7034** | **不染色島升起**，顯示 **1-1 認知塔** |
| 4 → 5 | 完成不染色島的 1-1 認知塔，於遊戲下方輸入原遊戲青春密碼 **8704** | **2-1 情意塔升起** |

不染色島的 2-1 情意塔現已能由 1-1 通關解鎖；3-1 與不迷路島的三座塔目前保留鎖定，後續再接續設計。中央「教材寶庫」現已啟用：可在內嵌 PDF 閱讀器直接閱讀完整九頁《不需炫耀、不是比較》原始檔，或在內嵌視窗查看 Padlet（<https://padlet.com/caose29103970/115-11-14-ai-s023z1hlike9bytgguh2?lang=zh-TW>）。若嵌入不支援或受分享權限限制，另有可直接開啟的 Padlet 網址。**原始 PDF 的插圖、排版與文字均由原始文件保留**。PDF 目前上傳至使用者的 Google Drive；如需對一般訪客公開，擁有者必須將檔案權限設為「知道連結的任何人可檢視」。為了保留四島闖關架構，本次不另外新增一座浮島。

### 試玩操作

1. 打開 [健康島](https://kaoelvmpvm.github.io/Health-Island/)。
2. 點擊中央 3D「教材寶庫」，選擇「完整 PDF／Padlet 交流／闖關路線」；完成閱讀後返回導覽員。
3. 在導覽員完成既有兩題行前檢核，喚醒不炫耀島；點擊 1-2 認知塔開始互動遊戲。
4. 完成每份互動教材後，直接在同一教材視窗下方輸入通關密碼，驗證成功後按「前往下一座教材塔」，不必返回導覽員。
5. 完成 3-2 成功路徑後，在教材下方輸入密碼，觀察不染色島升起；挑戰 1-1 並輸入其青春密碼，可繼續解鎖 2-1。
6. 開啟導覽小人，可看到目前進度；「重設本機闖關進度（測試用）」能重新體驗全部動畫。

**舊版進度相容：** v0.5 已儲存的階段 0、1、2 仍沿用。進度目前保留在這個瀏覽器的 `localStorage`，關閉後重開仍可恢復。隱私模式、更換裝置或清除網站資料後，可能無法保留進度。

**評量限制：** 現有教材通關碼是公開靜態網頁中的固定值，本原型僅驗證使用者輸入，**不能證明本人實際完成遊戲**。若要建立可靠的成績或學生個別完成紀錄，應改以經認證的完成事件與後端資料服務驗證。

### 核心檔案

| 檔案 | 功能 |
|---|---|
| `index.html`、`styles.css` | 網站架構與外觀 |
| `app.js` | 主島、海水、光影、動畫及場景初始化 |
| `satellites.js` | 三座主題浮島與空中踏石 |
| `quest-rules.js` | 解鎖階段、塔樓及島嶼門檻、原教材密碼 |
| `guide.js`、`guide.css` | 3D 導覽小人、閱讀檢核、進度、密碼與提示 |
| `lessons.js`、`learning.css` | 教材塔、升起動畫、嵌入原遊戲、教材下方密碼輸入及直接前往下一塔 |
| `vault.js`、`vault.css`、`vault-learning.js` | 中央教材寶庫、九頁完整 PDF 內嵌閱讀器、Padlet 嵌入與返回導覽員 |
| `data/lessons.json` | 9 個原始教材的名稱和 GitHub Pages 連結 |

本次只修改健康島 Repository，未更動原本的 `youth-*` 教材網站。
