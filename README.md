# 健康島 Health Island

## v0.5｜導覽員與逐步解鎖世界（可玩原型）

中央健康島除了既有的「教材寶庫」之外，新增低多邊形 **3D 導覽小人**、行前閱讀與兩題學習檢核。這版把原先一進站就能看到四座島及九座塔的展示模式，改成「先完成任務，世界才會逐步出現」。

### 目前可完整測試的流程

1. **進入中央健康島**：首次開啟自動顯示導覽小人的說明；也能點擊小人或「🧭 閱讀任務」進入任務面板。
2. **閱讀示範教材**：站內有三段暫定的行前閱讀，介紹尊重界線、三種學習面向與解鎖規則。此內容僅用來測試遊戲機制，**不是正式教材區的教材**。
3. **完成兩題檢核**：兩題都正確才會觸發不炫耀島從海面下升起。此時只會出現 **1-2 認知塔**。
4. **進入原始 1-2 教材**：「青春補給－不炫耀」在自己的 GitHub Pages 執行。完成原本九題挑戰後，取得該遊戲的青春密碼。
5. **回導覽員輸入青春密碼**：通過本機驗證後，**2-2 情意塔**從島上升起，可進入原始的「青春心語 Yes－不炫耀」徽章提示語教材。
6. **尚未開發的後續關卡**：3-2 技能塔及不染色島、不迷路島仍保持鎖定，將在下一階段補上解鎖規則，不會假裝已完成。

### 目前的解鎖條件

| 進度階段 | 3D 場景狀態 | 觸發 |
|---|---|---|
| 0（初次） | 僅中央健康島與導覽員 | 尚未完成閱讀檢核 |
| 1 | 不炫耀島升起，出現 1-2 認知塔 | 兩題行前檢核皆正確 |
| 2 | 不炫耀島的 2-2 情意塔也升起 | 輸入 1-2 原始教材的青春密碼 |

其他分島及尚未解鎖的塔樓，在世界場景及教材目錄均受到進度限制。初次開啟的進度會存於此瀏覽器的 `localStorage`，重新整理後可以恢復；導覽員的任務面板有「重設本機闖關進度（測試用）」供反覆驗證動畫。

**安全與評量限制：** 目前密碼是既有原教材的固定通關碼，前端只能驗證輸入值，無法確實證明使用者本人完成了原遊戲。瀏覽器進度也不會自動跨裝置同步。若日後用於正式評量，應改成遊戲完成訊號與可信後端驗證，並視需求建立學生身分與紀錄系統。

### 原本功能保留

- 中央 3D 健康島的自然地景、樹木、瀑布、水面、日夜景觀及視角操作
- 中央「教材寶庫」保留為**未來正式教材區的入口佔位**，**目前沒有外部跳轉連結**
- 三座獨立主題島及原本九份青春系列教材的資料對應
- 教材資訊卡、站內內嵌視窗、另開原始 GitHub Pages 的連結
- 桌機與手機介面

### 程式模組

| 檔案 | 用途 |
|---|---|
| `app.js` | 3D 主場景、動畫更新與模組初始化 |
| `guide.js`, `guide.css` | 3D 導覽員、行前閱讀、檢核、密碼驗證、本機進度、導覽視窗 |
| `satellites.js` | 三座浮島與空中踏石的獨立場景 |
| `lessons.js`, `learning.css` | 九座教材建築、世界導覽、解鎖顯示、教材資訊及內嵌視窗 |
| `vault.js`, `vault.css` | 中央教材寶庫（尚未連結正式教材區） |
| `data/lessons.json` | 九份原始教材網站與名稱資料 |
| `index.html`, `styles.css` | 網頁骨架與基本樣式 |
