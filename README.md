# 健康島 Health Island

3D 互動健康教育世界。目前為 **v0.2 — 青春系列學習聚落**，保留 v0.1 的低多邊形島嶼、池塘、溪流、瀑布、樹木、海水、雲朵、飛鳥、日夜光影、旋轉縮放等功能。

## 青春系列：三主題 × 三面向

| 學習面向 | 不染色 | 不炫耀 | 不迷路 |
|---|---|---|---|
| 認知 · 青春補給 | 1-1 | 1-2 | 1-3 |
| 情意 · 青春心語 Yes | 2-1 | 2-2 | 2-3 |
| 技能 · 青春練功 | 3-1 | 3-2 | 3-3 |

九份教材原始 Repository 及 GitHub Pages 網址收錄在 `data/lessons.json`。教材仍由原始網站維護，本 Repo 不複製教材程式或素材，保留原教材的版本獨立性。

## 互動方式

- 三個主題聚落（不染色：綠、不炫耀：紫、不迷路：橘）
- 每個聚落三種 3D 入口：知識亭（認知）、心語屋（情意）、練功塔（技能）
- 點擊 3D 建築或上方浮動編號，可開啟教材資訊
- 點「進入互動教材」可在本站嵌入原網站操作；亦可直接另開分頁
- 右上角「青春探索地圖」提供九份教材清單，便於手機與鍵盤使用
- 拖曳旋轉、滾輪或雙指縮放、日夜切換、自動旋轉及重設視角

## 啟用 GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save。

預定網址：https://kaoelvmpvm.github.io/Health-Island/

首次發佈需要等待 GitHub Pages 完成部署。網頁需要支援 WebGL 與 ES Modules 的現代瀏覽器，並連線到 Three.js CDN。

## 檔案與擴充

| 檔案 | 功能 |
|---|---|
| `index.html`、`styles.css` | 網頁外觀與初始控制 |
| `app.js` | 3D 浮島、植栽、水系、光影與環境動畫 |
| `data/lessons.json` | 九份教材名稱、類型、Repository 與入口連結 |
| `lessons.js` | 3D 教學建築、互動熱點、教材總覽及嵌入視窗 |
| `learning.css` | 教材面板、地圖與手機排版 |

本版本尚未實施跨裝置實際畫面測試與效能基準測量，第三方教材頁面的 iframe 行為也應以瀏覽器實測為準。若嵌入不成功，可點選「另開分頁」。
